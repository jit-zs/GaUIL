GaUIL
=====

This is a GUI engine uses a list of user defined callbacks to interface with most GUI libraries.

# CMake
```CMake
target_link_libraries(project_name PRIVATE GaUIL)
```

If you need any help just submit an issue. The repo is in its early stages so it doesn't really matter how many issues you make.
Demo/Examples can be found in the dev folder
