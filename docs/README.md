# Documentation 


- ## Text packs

Text packs are used in UI functions like ``gauil::button`` to compress a lot of data into a single string
- The drawn text is all text before [$$]
- The ID is all text before [@@]
- The style is all text after [@@]
Example: ``Options[$$]MainMenu[@@]OptionsButton``
  - Drawn Text: ``Options``
  - ID: ``Options[$$]MainMenu``
  - Style: ``OptionsButton``
